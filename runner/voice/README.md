# Binix Voice runner

Thư mục khởi đầu để bạn tự viết tính năng treo Voice.

- Viết phần kết nối của bạn trong `run_voice()` tại `main.py`.
- Sao chép `config.example.json` thành file cấu hình riêng trên host.
- Không đặt token Discord trực tiếp trong mã hoặc commit file chứa token.
- Thư mục này hiện chưa được nối với dashboard hay runner RPC.
