# Binix Auto Quest runner

Thư mục khởi đầu để bạn tự viết phần Auto Quest.

- Viết luồng của bạn trong `run_auto_quest()` tại `main.py`.
- Chỉ triển khai cách dùng tuân thủ điều khoản của Discord.
- Giữ token và thông tin đăng nhập ngoài mã nguồn.
- Thư mục này hiện chưa được nối với dashboard hay runner RPC.
